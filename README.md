# موبایل کارکرده

بازار ویژهٔ همکاران برای خرید و فروش موبایل، ساعت هوشمند و اسپیکر کارکرده (PWA، راست‌چین، موبایل‌محور و سازگار با لپ‌تاپ).

طراحی در Figma: https://www.figma.com/design/HsN5bEkGGi10eXW2IEJ4Xm

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # ساخت نسخهٔ نهایی + Service Worker
npm run verify   # typecheck + lint + بررسی معماری + تست‌ها
```

ساختار پروژه (Feature-Sliced Design) و راهنمای «کجا چه چیزی را ویرایش کنم؟» در [ARCHITECTURE.md](ARCHITECTURE.md) توضیح داده شده است.

## وضعیت فعلی (نمونهٔ اولیه فرانت‌اند)

انجام شده:
- صفحات: خانه، محصولات (فیلتر، نمای کارت/جدول)، صفحهٔ محصول، دربارهٔ ما، ثبت دستگاه، ورود، سبد
- PWA قابل نصب (manifest + service worker)
- ثبت دستگاه: قالب عکس برای هر دسته (موبایل/ساعت/اسپیکر)، دوربین با کادر راهنما، پاک‌شدن EXIF با بازکدگذاری عکس، هشدار عکس تار/تاریک/کم‌وضوح
- مسدودسازی شماره تلفن و آیدی شبکه‌های اجتماعی در توضیحات (برای حفظ نقش واسطه)
- نمایش قیمت فقط بعد از ورود

هنوز انجام نشده (نیازمند سرور):
- ورود واقعی با پیامک و تأیید همکار (الان فقط نمایشی است)
- ذخیرهٔ آگهی‌ها و عکس‌ها، پنل مدیریت و تأیید آگهی
- حذف پس‌زمینه و جایگزینی با پس‌زمینهٔ استاندارد (پیشنهاد: rembg روی سرور)
- ثبت سفارش واقعی؛ داده‌های محصولات در `src/entities/product/api/mock-products.ts` نمونه هستند
